## 用户故事

**作为** 系统管理员，**我希望** 将 API 配置（含请求控制与字段权限）以 JSON 导出到剪贴板、并从剪贴板导入，**以便** 在环境间快速迁移与备份 API 配置。

## 需求描述

1. 功能入口：API 管理页左下角提供「导出」（下拉：导出全部 / 导出选中）与「导入」按钮
2. 导出：结果为标准 JSON（业务字段 + requestControl 对象 + `fields[]` 字段权限），直接复制到系统剪贴板，无文件下载
3. 导入：模态弹窗内使用 monaco-editor 作为 JSON 编辑器（语法高亮）；按「接口编码」判断存在性——已存在更新、不存在新增，全程不做删除
4. 校验：每项必填 应用编码（appCode）、接口编码（apiCode）、请求方法、请求URI；字段权限项必填 字段编码（fieldCode，数据权限精准匹配标识，不允许后端生成）、字段名称、JSON路径、权限动作（HIDDEN/MASK/READ_ONLY），脱敏动作必填脱敏规则；任一不合法整体阻止导入并逐条提示
5. 禁止循环查库：导出两条批量查询（主数据 + 字段权限 IN），导入按批量查询划分新增/更新后分块批量落库；循环仅存在于内存运算

## 验收标准

1. 导出全部遵循页面当前筛选条件（与列表查询同语义，含 menuBindStatus），无分页限制
2. 导出选中仅导出勾选行，前端传 `ids`（逗号串，Spring 自动绑定 `List<Long>`）
3. 导入 JSON 解析失败 / 非数组 / 缺必填项 / 编码重复 / 动作不合法时，前端整体阻止提交并给出明细；后端二次校验兜底
4. 字段权限按 `(apiCode + fieldCode)` 匹配：存在更新、不存在以导入的 fieldCode 新增；JSON 缺 fieldCode 判为校验失败
5. 导入返回新增/更新 API 数与新增/更新字段权限数明细，成功后刷新列表
6. 批量分块 200 条/批，避免单 SQL 过大；新增走 `insertBatch`，更新走 `updateBatch4Import`（CASE WHEN 逐行设值单 SQL）

## 导出 JSON 结构示例

```json
[
  {
    "module": "iam-admin",
    "appCode": "app_xxx",
    "apiCode": "api_xxx",
    "apiMethod": "POST",
    "apiUri": "/iam-admin/api/create",
    "apiName": "API创建",
    "writeFlag": 1,
    "requestControl": {"enable": true, "mutex": {"enable": true, "timeoutSeconds": 30}},
    "remark": null,
    "sort": 1,
    "fields": [
      {"fieldCode": "field_xxx", "fieldName": "手机号", "jsonPath": "$.phone", "action": "MASK", "maskRule": "3,4", "description": null, "sort": 1}
    ]
  }
]
```

## 技术实现要点

- `GET /iam-admin/api/export`（`ApiExportReq`/`ApiExportResp`）：`ids` 有值按 `selectByIds` 批量取选中项，否则复用 `getApiList` 全量筛选；字段权限 `IamApiFieldMapper.getFieldsByApiCodes` 一次 IN 查询，内存按 apiCode 分组组装
- `POST /iam-admin/api/import`（`ApiImportReq`/`ApiImportResp`）：`@Transactional` 内先 `validateImport` 内存校验，再 `getApis4Paste` 批量查已存在数据划分 inserts/updates；updates 走自定义 XML `updateBatch4Import`（`CASE id WHEN ... THEN ...`，`version = version + 1`，`update_time` 由数据库自动填充，`update_by` 由 `MyBatisUpdateInterceptor` 植入实体后随 CASE 写入）
- `getApis4Paste` 查询补充 `id/sort/version` 列（导入更新需要主键，同时修复原实现缺主键的隐患）
- 分块使用 Guava `Lists.partition(list, 200)`
- 前端：`api.js` 新增 `apiExport`/`apiImport`；`index.vue` 左下角新增导出下拉（loading 态）与导入按钮；新增 `components/import.vue`（monaco-editor + 前置校验 + 成功明细提示），错误提示由 ui-core request 拦截器统一弹出

## 边界与异常

- 批量操作分块 200，循环仅用于内存分组与分块
- 操作全程 loading：导出按钮 loading、导入确定按钮 loading
- JSON 解析失败、校验失败、请求异常统一捕获提示，不崩页；请求级错误由全局拦截器提示
