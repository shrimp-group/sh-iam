## 用户故事

**作为** 门户侧业务功能， **我希望** 提供一个用户选择分页查询接口， **以便** 下拉选择、人员挑选等场景按条件筛选启用状态的用户。

## 验收标准

1. 接口：`GET /iam-portal/user/select`（会话鉴权，非白名单路径）
2. 入参（`UserSelectReq`，继承 PageReq，均可空）：`username`（用户名，LIKE 模糊）、`nickname`（姓名，LIKE 模糊）、`gender`（性别，精确）、
   `current`/`size`（分页）
3. 出参：`R<PageData<UserSelectResp>>`，每条记录仅含 `username`、`nickname`、`gender`
4. 固定过滤：`deleted = 0` 且 `user_status = 1`（仅启用用户）
5. 排序：`username ASC`

## 技术实现要点

- 分层 Rest → Service → Mapper：`UserInfoRest.userSelect` → `SsoUserService.getUserSelectPage`（复用 `PageQuery.page`）→
  `SsoUserMapper.getUserSelectPage`
- Mapper 结果直接映射 `UserSelectResp`（仅 SELECT `username, nickname, gender`），不经过 IamUser 全字段实体
- `<if test>` 条件拼装，字符串条件含空串判断，避免空串触发 `LIKE '%%'` 全匹配
- Service 入口 `log.info`、异常出口 `log.error` 后原样抛出
- 单元测试 `SsoUserServiceTest`：条件透传、空条件、异常出口三场景
