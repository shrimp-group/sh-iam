## 用户故事

**作为** 接入子系统的用户，**我希望** 登录页展示我正在访问的目标系统名称，**以便** 明确当前登录归属的应用。

## 验收标准

1. 公开接口：`GET /iam-portal/public/sso/app-info?appCode={appCode}`
2. 响应体严格字段白名单：仅返回 `appName`、`loginBgp`（登录页背景图），不暴露 IamApp 其余字段
3. 应用不存在（或已逻辑删除）返回 `R.ok` 且 data 为 null；appCode 为空由 `@NotBlank` 拒绝
4. 登录页从 `redirect` 参数解析应用编码：绝对 URL 且 hostname 含 `.` 且非 IPv4 → 取域名首段；否则（无 redirect / 相对路径 / localhost / IP）回退 `portal`
5. 标题格式 `{appName}-单点登录{envSuffix}`，同时作用于 `document.title` 与登录表单上方 `<h3>`；envSuffix：local/dev/sit/uat 为 `【X】`，prod 为空
6. `loginBgp` 非空时作为登录页背景图（cover 居中），为空保持 CSS 渐变兜底
7. 应用信息请求静默失败（catch 空处理），回退 `runtimeEnv.title`，不阻塞登录流程

## 技术实现要点

- Mapper 结果直接映射 `SsoAppInfoResp`（仅 SELECT `app_name, login_bgp`），不经过 IamApp 全字段实体
- `#{}` 预编译传参 + `deleted = 0` 过滤
- 前端 `env.js` 导出 `envSuffix`（复用现有 env 判定），`runtimeEnv` 聚合
- `resolveAppCode()` 用 `new URL(redirect)` 提取 hostname，IPv4 正则排除
